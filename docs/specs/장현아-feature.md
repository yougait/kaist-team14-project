# Feature Spec — Running Insight Card (장현아)

Last updated: 2026-10-24
WhyTree: [docs/whytree/장현아.md](../whytree/장현아.md)
Prototype: [prototypes/장현아/index.html](../../prototypes/장현아/index.html)

## 한 줄 요약

초보 러너가 **케이던스(분당 걸음 수, spm)** 하나의 뜻을 쉬운 말로 이해하도록 돕는 모바일 결과 카드. 실제 센서 데이터가 아직 검증되지 않았으므로 **데모 데이터**로만 보여 준다.

## 연결된 문제 (WhyTree)

- **A1.** 전문 용어가 생소하다 → "케이던스"를 일상 언어로 설명한다.
- **A2.** 측정 수치가 의미하는 바를 모른다 → 숫자와 함께 참고 범위 안에서의 위치를 보여 준다.

## 대상과 사용 상황

- **대상:** 러닝 지표를 처음 접하는 초보 러너
- **상황:** 마라톤 행사 부스에서 휴대폰이나 태블릿 브라우저로 결과 카드를 본다.

## 원칙

1. **데모임을 숨기지 않는다.** 데모 값과 데모 참고 범위는 실제 측정 결과나 검증된 기준이 아님을 화면에 항상 표시한다.
2. **판단하지 않는다.** 좋음/나쁨 등급, 경고 색, 점수를 쓰지 않는다.
3. **처방하지 않는다.** "케이던스를 ○○로 바꾸세요" 같은 행동 지시를 쓰지 않는다.
4. **의학적 주장을 하지 않는다.** 부상, 통증, 무릎 건강과 수치를 연결하지 않는다.

## 요구사항

### P0 — 이번 과제에서 반드시 구현

| ID | 요구사항 |
|---|---|
| P0-1 | 지표 이름 "케이던스"와 단위 "spm(분당 걸음 수)"를 표시한다. |
| P0-2 | 데모 값 **165 spm**을 큰 숫자로 표시한다. |
| P0-3 | 숫자 아래에 한 줄 쉬운 설명을 표시한다. (예: "1분 동안 발이 땅에 닿은 횟수예요.") |
| P0-4 | 카드 맨 위에 「데모 데이터」 배지를 항상 보이게 표시한다. |
| P0-5 | 숫자 바로 아래에 "예시 값이며 실제 측정 결과가 아닙니다"를 표시한다. |
| P0-6 | 데모 데이터는 HTML 상단의 별도 객체(`DEMO_DATA`)로 분리해, 화면 코드를 고치지 않고 값을 바꿀 수 있게 한다. |
| P0-7 | 빌드 없이 브라우저에서 파일을 열면 바로 실행된다. 외부 라이브러리와 네트워크 요청이 없다. |
| P0-8 | 휴대폰 너비(360px)부터 태블릿까지 가로 스크롤 없이 보인다. |

### P1 — 이번 과제에서 구현

| ID | 요구사항 |
|---|---|
| P1-1 | 참고 범위 막대에 데모 참고 범위(160~180 spm)와 내 값(165 spm)의 위치를 표시한다. |
| P1-2 | 막대 아래에 "데모용 참고 범위 · 개인차 있음 · 의학적 기준 아님"을 표시한다. |
| P1-3 | 막대와 범위에는 좋음/나쁨을 암시하는 색(초록/빨강 등)을 쓰지 않는다. |
| P1-4 | '자세히 보기'를 누르면 세 가지 설명이 펼쳐지고, 다시 누르면 접힌다. ① 케이던스는 이렇게 세요 ② 왜 사람마다 다를까요 ③ 이 데이터에 대해 |
| P1-5 | '자세히 보기'는 키보드와 화면 읽기 프로그램으로도 쓸 수 있다. |
| P1-6 | 시스템 설정에 따라 라이트 모드와 다크 모드를 모두 지원한다. |

### P2 — 이번 범위 밖 (나중에)

| ID | 요구사항 |
|---|---|
| P2-1 | 실제 KNEECH 센서 데이터 연동 (`DEMO_DATA` 자리를 실제 데이터로 교체) |
| P2-2 | 키·속도·경험을 반영한 개인화 AI 설명 |
| P2-3 | 같은 조건 재측정 비교 |
| P2-4 | 측정 조건과 불확실성 표시 (WhyTree C1, C2) |

### 하지 않는 것

- 행동 처방, 등급이나 평가, 의학적 판단
- 화면 안의 입력칸, 퀴즈, 데이터 저장이나 전송
- 영어 등 다른 언어 지원

## 수동 테스트 기준

브라우저에서 `prototypes/장현아/index.html`을 직접 열고 확인한다.

| # | 확인 방법 | 통과 기준 | 관련 요구사항 |
|---|---|---|---|
| T1 | 파일을 더블클릭하거나 브라우저로 연다. | 빌드 없이 카드가 바로 보이고, 콘솔에 오류가 없다. | P0-7 |
| T2 | 첫 화면을 본다. | "케이던스", "spm", "165"가 보인다. | P0-1, P0-2 |
| T3 | 첫 화면을 본다. | 한 줄 쉬운 설명이 숫자 아래에 있다. | P0-3 |
| T4 | 스크롤하지 않고 첫 화면을 본다. | 「데모 데이터」 배지와 "실제 측정 결과가 아닙니다" 문구가 보인다. | P0-4, P0-5 |
| T5 | `DEMO_DATA.value`를 172로 바꾸고 새로고침한다. | 숫자와 막대 위 내 위치가 함께 바뀐다. | P0-6, P1-1 |
| T6 | 개발자 도구에서 너비 360px로 본다. | 가로 스크롤이 없고 글자가 잘리지 않는다. | P0-8 |
| T7 | 막대를 본다. | 160~180 범위와 165 표시가 보이고, 아래에 "데모용 · 개인차 · 의학적 기준 아님" 문구가 있다. | P1-1, P1-2 |
| T8 | 막대 색을 본다. | 초록/빨강처럼 좋고 나쁨을 암시하는 색이 없다. | P1-3 |
| T9 | '자세히 보기'를 누르고, 다시 누른다. | 세 가지 설명이 펼쳐졌다가 접힌다. | P1-4 |
| T10 | Tab 키로 '자세히 보기'에 이동해 Enter를 누른다. | 키보드만으로 펼치고 접을 수 있다. | P1-5 |
| T11 | OS를 다크 모드로 바꾼다. | 배경과 글자가 함께 바뀌고 읽기 어렵지 않다. | P1-6 |
| T12 | 화면의 모든 문장을 읽는다. | 처방, 등급, 부상·통증·건강 관련 표현이 없다. | 원칙 2~4 |

## 검증 (사용자 인터뷰)

카드 안에는 검증 질문을 넣지 않는다. 부스 인터뷰에서 진행자가 묻고 기록한다. 질문과 관찰 기준은 [prototypes/장현아/README.md](../../prototypes/장현아/README.md)에 있다. 아직 실제 사용자 테스트는 진행하지 않았다.
