## 1. 실제 사용 환경과 테스트 환경의 차이

- **Risk:** 마라톤 행사 부스에서는 좋은 평가를 받았지만, 실제 러닝 환경에서는 사용성이 떨어질 가능성
- **Why:** 행사장에서의 단기 체험과 일상적인 러닝 중 센서를 착용하고 데이터를 확인하는 경험은 다를 수 있음.
- **Mitigation:** 행사장 체험뿐 아니라 실제 러닝크루를 대상으로 반복 사용 테스트를 진행하고, 사용 과정에서 발생하는 불편 요소를 확인

## 2. 고객의 행동 변화로 연결되지 못할 가능성

- **Risk:** AI가 자세 교정 방법을 제안하더라도 러너가 실제로 행동을 바꾸지 않아 서비스의 효과가 제한될 가능성
- **Why:** 잘못된 자세를 오랫동안 유지해 온 러너는 AI의 제안을 이해하더라도 기존 습관을 바꾸기 어렵고, 교정 과정 자체를 번거롭게 느낄 수 있음. (운동 특성상 코치가 지속적으로 모니터링하면서 바른 자세로 운동할 수 있게 바꾸지 않는 이상 자신의 운동 자세를 직접 바꾸는 건 어려운 일일 수 있음)
- **Mitigation:** 한 번에 여러 가지 교정 방법을 제안하기보다 가장 중요한 행동 한 가지를 추천하고, 재측정을 통해 변화 여부를 확인

## 3. 초기 테스트 고객의 편향으로 인한 시장성 과대평가

- **Risk:** 기존 러닝크루나 행사 참가자 중심의 테스트 결과가 일반 러너들의 실제 수요를 대표하지 못할 가능성
- **Why:** 기존 협력 관계가 있는 러닝크루 회원이나 행사 참가자는 러닝에 대한 관심이 높고, 새로운 기술에 긍정적으로 반응할 가능성이 있음.
- **Mitigation:** 기존 러닝크루 외 일반 러너도 인터뷰에 포함하고, 러닝 경험과 참여 경로별로 결과를 구분하여 분석
