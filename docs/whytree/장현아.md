# KNEECH WhyTree — 장현아

## North Star
러너가 자신의 러닝 자세를 이해하고 더 나은 러닝 습관을 형성하도록 돕는다.

## Core Problem
러너는 자세 분석 결과를 받아도 그 의미를 쉽게 이해하기 어렵다.

## WhyTree

- **A. 분석 정보를 이해하기 어렵다**
  - A1. 전문 용어가 생소하다.
  - A2. 측정 수치가 의미하는 바를 모른다.
- **B. 정보를 해석하고 판단하기 어렵다**
  - B1. 어떤 지표가 중요한지 모른다.
  - B2. 수치가 나타내는 상태를 이해하기 어렵다.
- **C. 결과를 신뢰할 수 있는지 판단하기 어렵다**
  - C1. 측정 조건이 결과에 미치는 영향을 모른다.
  - C2. 분석의 한계와 불확실성을 알기 어렵다.

## How — 해결 방향 (가설)

- 전문 용어를 일상적인 언어로 설명한다.
- 측정 수치와 함께 그 의미를 설명한다.
- 사용자가 먼저 이해해야 할 핵심 인사이트 하나를 강조한다.
- 데이터의 한계와 불확실성을 명확히 표시한다.

## What — 이번 HW6에서 구현할 기능

**Running Insight Card**

러닝 분석 지표 하나를 쉬운 설명과 함께 보여주는 인터랙티브 결과 카드.

- 연결된 WhyTree 노드: A1, A2
- P0: 지표 하나와 단위, 쉬운 설명, 시뮬레이션 데이터 안내 표시
- P1: 시각적 표현 및 자세히 보기 기능
- P2: 실제 센서 데이터 연동, 개인화된 AI 설명, 재측정 비교

## Validation — 검증할 질문

- 러너가 지표의 의미를 자신의 말로 설명할 수 있는가?
- 결과 화면에서 어떤 정보를 가장 먼저 확인하는가?
- 결과를 이해하는 데 추가로 필요한 설명은 무엇인가?

> Note: WhyTree에 기재한 사용자 문제와 원인은 아직 사용자 조사로 검증되지 않은 가설이다.
