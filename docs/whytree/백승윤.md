표기: **[씨앗]** = 지금 하는 일 중 먼저 떠오른 다섯 가지, **[현재]** = 지금 하는 다른 일, **[새 방법]** = 아직 하지 않는 일(슬라이드의 점선 상자). 위로 갈수록 목적(why)이고, 아래로 갈수록 방법(how)이다.

## WhyTree

- **러너가 부상 없이 오래 달린다**
  - **A. 내가 "어떻게" 달리는지 안다**
    - A1. [씨앗] 니치 러닝 측정 (관절가동범위·착지 습관·좌우 밸런스)
    - A2. [씨앗] 보행 검사
    - A3. [현재] 인체계측
    - A4. [새 방법] 스마트폰 카메라로 자세 촬영
  - **B. 결과를 이해하고 믿는다**
    - B1. [현재] 전문가(의사·물리치료사)의 설명
    - B2. [새 방법] 쉬운 말 리포트
    - B3. [새 방법] 측정 조건과 한계를 표시
  - **C. 실제로 자세를 바꾼다**
    - C1. [씨앗] AI 맞춤 운동 콘텐츠
    - C2. [씨앗] 보행 훈련
    - C3. [새 방법] 가장 중요한 교정 행동 하나만 제안
    - C4. [새 방법] 같은 조건에서 재측정해 변화 확인
    - C5. [새 방법] 다음 러닝 직전에 리마인드
  - **D. 더 많은 러너가 써 보게 한다**
    - D1. [씨앗] 마라톤 행사 부스 체험
    - D2. [현재] 러닝크루(동구동런)
    - D3. [현재] 운동선수·인플루언서 추천

## Notes

- 「C. 실제로 자세를 바꾼다」 가지는 내 프리모텀 #2 "AI의 교정 제안이 고객의 행동 변화로 연결되지 못했다"에서 나왔다.
- B2 쉬운 말 리포트는 장현아의 Running Insight Card와 같은 방향이다.
- 이 트리의 목적과 방법은 아직 사용자 조사로 검증하지 않은 가설이다.
