# KNEECH 다음 러닝 코칭 카드

유중경의 HW6 개인 프로토타입입니다. 합성 자료에서 행동 한 가지를 확인하고, 실행 날짜와 체크인을 연결해 같은 브라우저에서 다시 봅니다.

## 열기

이 폴더의 `index.html`을 Chrome 또는 Edge에서 엽니다. 설치, 서버, API 키가 필요하지 않습니다. 파일을 이동하거나 다른 브라우저로 열면 저장 기록을 공유하지 않을 수 있으므로 같은 위치와 브라우저에서 확인합니다.

브라우저가 로컬 파일 저장을 막는 환경에서는 저장 오류를 표시합니다. 예시 자료는 `fixtures/approved.json`입니다. 화면의 ‘합성 JSON 불러오기’에서 파일을 선택하거나 내용을 붙여넣을 수 있습니다.

## 기능

- 승인된 데모·미승인 데모·단측 누락·과제 불일치 상황 선택
- 행동 확인과 실행 날짜 저장, 실행 후 체크인, 지난 계획·체크인 재조회
- 새 불편과 미승인 자료의 검토 필요 표시, 누락과 비교 보류 사유 표시
- 새로고침 복원, 중복 저장 차단, 인쇄, 확인 후 이 앱 자료만 초기화

생성 AI 모델은 사용하지 않습니다. 실제 센서 연결·알림·회원 계정·서버 저장도 없습니다. ‘승인됨’은 데모 자료 안의 가상 상태입니다. 실제 건강 자료나 연락처를 넣지 마세요. 자가보고는 센서 측정이나 건강 개선의 근거가 아닙니다.

## 손으로 확인할 세 가지 검사

자세한 완료 조건은 `../../docs/specs/유중경-next-run.md`의 T1–T3와 같습니다. 검사 결과는 직접 수행한 뒤 `TEST_RESULTS.md`의 본인 검사 항목에 적습니다. 아래 절차를 작성한 사실은 통과를 의미하지 않습니다.

### T1 정상 흐름과 저장 복원

1. 초기화 후 승인된 데모를 고릅니다. 행동 확인 없이 또는 빈 날짜로 저장하면 거절되는지 확인합니다.
2. 확인 체크 후 오늘이나 미래 날짜로 계획을 저장합니다. 다시 눌러 중복 계획이 생기지 않는지 확인합니다.
3. 새로고침하여 행동과 날짜가 남는지 봅니다. ‘일부 실행’, 어려움, ‘새 불편 없음’을 저장하고 다시 새로고침합니다.
4. 지난 기록에 날짜·실행 상태·어려움이 남는지 확인하고 인쇄 미리보기에서 같은 내용과 데모 표시를 확인합니다.

### T2 진행 차단과 자료 해석

1. 미승인 데모에서 계획 저장이 막히고 담당자 검토 필요가 표시되는지 봅니다.
2. 승인된 데모로 계획을 만든 후 새 불편 ‘있음’을 기록합니다. 검토 필요와 진행 차단이 유지되는지 확인합니다.
3. 단측·누락 데모에서 ‘자료 없음’, ‘단측’을 확인합니다. 누락값이 0이나 좌우 균형 점수로 나오면 실패입니다.
4. 과제 불일치 데모에서 ‘비교 보류: 과제 다름’을 확인합니다. 개선률이 나오면 실패입니다.

### T3 잘못된 입력과 초기화

1. 예시 JSON을 불러온 후 mode를 real로 바꾸거나 잘못된 JSON을 붙여넣습니다. 오류가 뜨고 기존 기록이 유지되는지 확인합니다.
2. 저장이 차단된 환경에서 저장 완료로 잘못 표시하지 않는지 확인합니다. 일반 브라우저에서 이 환경을 만들기 어렵다면 미검사로 남깁니다.
3. 초기화 확인창에서 취소해 기록 보존을 확인한 뒤, 다시 초기화하여 이 앱 기록만 지워지는지 확인합니다.

## 자동 검사

Node.js가 있는 환경에서 이 폴더에서 다음을 실행합니다.

```text
node --test tests/core.test.js
```

이 검사는 날짜·상태 전이·자료 검증·복원·중복·저장 실패를 확인합니다. 브라우저의 실제 클릭이나 본인의 수동 검사를 대신하지 않습니다.

## 파일

- `index.html`, `style.css`, `app.js`: 화면과 브라우저 동작
- `core.js`: 자료 검증·상태 변화·저장 규칙
- `fixtures/approved.json`: 공개 가능한 합성 입력 예시
- `tests/core.test.js`: 상태와 예외 처리를 확인하는 자동 검사
- `assets/`: 원본 WhyTree 및 미리보기

저장은 `kneech.hw6.yougait.v1`이라는 localStorage 키 하나에 한정합니다. 출력은 화면의 같은 자료를 사용합니다. 외부 통신이나 추적 스크립트는 없습니다.
