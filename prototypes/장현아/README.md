# Running Insight Card — 장현아

초보 러너가 **케이던스(분당 걸음 수, spm)** 의 뜻을 이해하도록 돕는 모바일 결과 카드 시제품입니다.

- 요구사항과 수동 테스트 기준: [docs/specs/장현아-feature.md](../../docs/specs/장현아-feature.md)
- WhyTree: [docs/whytree/장현아.md](../../docs/whytree/장현아.md)

> ⚠️ 화면의 값(165 spm)과 참고 범위(160~180 spm)는 **데모 데이터**입니다. 실제 측정 결과나 검증된 의학적 기준이 아닙니다.

## 실행 방법

빌드나 설치가 필요 없습니다. `index.html`을 브라우저로 열면 됩니다.

```sh
open prototypes/장현아/index.html
```

부스에서 휴대폰이나 태블릿으로 열려면 파일을 기기에 옮기거나, 같은 와이파이에서 `python3 -m http.server`로 폴더를 띄운 뒤 접속합니다.

## 데모 데이터 바꾸기

`index.html` 맨 위의 `DEMO_DATA` 객체만 고치면 됩니다. 화면 코드는 바꾸지 않아도 됩니다.

| 필드 | 뜻 |
|---|---|
| `isDemo` | `true`이면 「데모 데이터」 배지와 안내 문구가 보입니다. |
| `value` | 보여 줄 케이던스 값 |
| `referenceRange` | 막대에 표시할 참고 범위 (현재 데모용 예시) |
| `scale` | 막대 양 끝 눈금 |

실제 센서 데이터를 연결할 때(P2)는 이 객체를 실제 값으로 채우는 코드로 바꿉니다. 그 전까지 `isDemo`는 `true`로 둡니다.

## 사용자 인터뷰 검증

카드 화면에는 질문이나 입력칸이 없습니다. 부스 진행자가 참가자에게 카드를 보여 준 뒤 말로 묻고 기록합니다. 참가자의 이름이나 연락처는 이 저장소에 기록하지 않습니다.

### 진행 순서

1. 참가자에게 "실제 측정이 아닌 예시 화면"이라고 먼저 알립니다.
2. 카드를 30초 정도 자유롭게 보게 합니다. 이때 진행자는 설명하지 않습니다.
3. 아래 질문을 순서대로 묻습니다.

### 검증 질문과 관찰 기준

| # | 질문 | 확인하려는 것 (WhyTree) | 관찰 기준 |
|---|---|---|---|
| Q1 | "방금 본 '케이던스'가 무엇인지 본인 말로 설명해 주시겠어요?" | 용어와 수치의 뜻을 이해했는가 (A1, A2) | **이해함:** "1분 동안 발이 땅에 닿은 횟수"라는 뜻을 자기 말로 설명한다. **부분 이해:** "걸음 수" 정도만 말하고 시간 기준(1분)이 빠진다. **이해 못 함:** 속도, 거리, 심박 등 다른 개념과 헷갈리거나 설명하지 못한다. |
| Q2 | "화면에서 가장 먼저 눈에 들어온 것은 무엇이었나요?" | 결과 화면에서 어떤 정보를 먼저 보는가 | 처음 언급한 요소를 기록한다. (숫자 / 데모 배지 / 참고 범위 막대 / 설명 문장 / 기타) 데모 배지나 안내를 알아챘는지도 따로 표시한다. |
| Q3 | "이 결과를 이해하는 데 더 알고 싶은 것이 있으셨나요?" | 추가로 필요한 설명은 무엇인가 | 요청 내용을 참가자의 말 그대로 적는다. '자세히 보기'를 스스로 눌렀는지도 기록한다. 참가자가 막대를 "좋다/나쁘다"로 해석했는지 따로 표시한다. |

### 기록 양식
